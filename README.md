# 中国人的脊梁断了吗？

从公开的文字上看起来：两天之前，我们总会自夸着“中华有为”，现在来了一个什么“皇帝”，却说一脚把中国人的脊梁踩断了。

于是有人慨叹曰：中国人的脊梁断了。

如果单据这一点现象而论，中国人的脊梁是早就断掉了的。先前说着什么“中华有为”，可是从来没有看着自己。如果说那也算是一种脊梁的话，那也只能说中国人曾经借着资本当作脊梁。自从这件事情之后，连资本当作的脊梁也都断掉了。
断掉了资本作的脊梁，就会反思，一个转身，也许能够只相信了人民百姓的脊梁，倒是一条新思路。不过现在还等着什么资本的喉舌吐出来一张带有那所谓“权威”印章的模糊图片，可就玄虚之至了。是真或是假，一时就找不出分明的结果来，它可以令人更长久的麻醉着自己，说到这是恶意为之。

某类人现在是在发展着“自欺力”。

“自欺”也并非新东西，只不过日见其明显，笼罩了一切罢了。然而，在这笼罩之下，我们有并不失掉自信力，没有断掉脊梁的中国人在。

我们从古以来，就有埋头苦干996的人，（有拼命硬干的人，有为民请命的人，）有舍身求法251的人，……虽是等于为资本唱颂歌的所谓“官方信息”，也往往掩不住他们的光耀，这就是中国的脊梁。

这一类的人们，也何尝少呢？他们在前仆后继的战斗，不过一面总在被摧残，被抹杀，消灭于黑暗中，不能为大家所知道罢了。说中国人失掉了自信力，断掉了脊梁，用以指一部分人则可，倘若加于全体，那简直是诬蔑。

要论中国人，必须不被搽在表面的自欺欺人的脂粉所诓骗。状元宰相的文章是不足为据的，要自己去看地底下。
